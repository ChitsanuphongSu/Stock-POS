# SP Toys POS

![SP Toys logo](assets/sp-toys-logo.png)

**โปรแกรมจัดการสต๊อกสำหรับร้านของเล่นบน Windows** พัฒนาด้วย Python และ PySide6 เพื่อให้ร้านบันทึกสินค้า พิมพ์บาร์โค้ด และรับเข้าหรือตัดสต๊อกด้วยเครื่องสแกนได้โดยไม่ต้องพึ่งบริการคลาวด์ ข้อมูลเก็บในเครื่องด้วย SQLite

> ชื่อโปรเจกต์ใช้คำว่า POS แต่แอปเวอร์ชันนี้ดูแล **สต๊อกสินค้าเท่านั้น** ไม่มีระบบราคา ชำระเงิน หรือรายงานยอดขาย

## ฟีเจอร์หลัก

- เพิ่มและแก้ไขรหัส ชื่อ หมวดหมู่ รูปภาพ และเกณฑ์แจ้งเตือนสต๊อกต่ำ
- สร้างบาร์โค้ด **Code 128** และแสดงตัวอย่างฉลากก่อนพิมพ์ ขนาดฉลากเริ่มต้น **50 × 30 มม.**
- สแกนเพื่อเลือกสินค้า ระบุจำนวน แล้วกดยืนยันก่อนรับเข้าหรือตัดสต๊อก รหัสใหม่แทนรหัสเดิมอัตโนมัติเมื่อสแกนสินค้าถัดไป
- ปรับยอดตามการนับจริง และดูประวัติการเคลื่อนไหวแยกตามวัน
- ส่งออกข้อมูลเป็น `.xlsx` และสำรอง/กู้คืนฐานข้อมูลพร้อมรูปสินค้า
- ใช้งานแบบออฟไลน์บนคอมพิวเตอร์ Windows

## ติดตั้งและใช้งานบน Windows

Repo นี้เผยแพร่ **ซอร์สโค้ด** ไม่ได้รวมไฟล์ `.exe` หรือข้อมูลสินค้าของร้าน วิธีเริ่มใช้งานจากซอร์ส:

1. ติดตั้ง [Python สำหรับ Windows](https://www.python.org/downloads/windows/) โดยเลือก **Add Python to PATH** ระหว่างติดตั้ง และติดตั้ง [Git](https://git-scm.com/downloads/win) หากยังไม่มี
2. เปิด PowerShell แล้วรันคำสั่ง:

   ```powershell
   git clone https://github.com/ChitsanuphongSu/Stock-POS.git
   cd Stock-POS
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   python main.py
   ```

   หาก PowerShell ไม่อนุญาตให้เปิดใช้งาน virtual environment ให้เรียก Python ในโฟลเดอร์นั้นโดยตรง:

   ```powershell
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe main.py
   ```

3. เมื่อเปิดแอปครั้งแรก ให้ไปที่เมนู **สินค้า** เพื่อเพิ่มสินค้า จากนั้นพิมพ์ฉลากและใช้เมนู **จัดการสต๊อก** เพื่อสแกนรับเข้าหรือตัดออก

แอปสร้างข้อมูลใหม่ที่ `%LOCALAPPDATA%\SP Toys\` โดยอัตโนมัติ การอัปเดตซอร์สหรือโปรแกรมไม่ลบฐานข้อมูลนี้ ควรใช้เมนู **ส่งออก / สำรอง** เพื่อสำรองข้อมูลเป็นประจำ

### สร้างไฟล์โปรแกรม `.exe`

หลังติดตั้ง dependencies แล้ว รันจากโฟลเดอร์โปรเจกต์:

```powershell
python -m PyInstaller --noconfirm SP-Toys-Stock.spec
```

เปิด `dist\SP Toys POS\SP Toys POS.exe` หรือคัดลอก **ทั้งโฟลเดอร์** `dist\SP Toys POS` ไปยังคอม Windows เครื่องอื่น ต้องคัดลอก `_internal` ไปพร้อมกับ `.exe` และไม่ต้องติดตั้ง Python บนเครื่องปลายทาง

หากต้องการไฟล์ตัวติดตั้ง `.exe` แบบ Setup ให้ติดตั้ง [Inno Setup](https://jrsoftware.org/isinfo.php) แล้วเปิด `installer.iss` เพื่อ Compile หลังสร้างโปรแกรมด้วย PyInstaller ไฟล์ Setup จะอยู่ใน `installer-output\` ผู้ใช้สามารถเลือกสร้างไอคอนบน Desktop ระหว่างติดตั้ง

### เครื่องสแกนและเครื่องพิมพ์ฉลาก

- เครื่องสแกนควรอ่าน Code 128 และส่งรหัสเหมือนแป้นพิมพ์ โดยตั้งให้ส่ง **Enter** หลังสแกน
- เครื่องพิมพ์ต้องมีไดรเวอร์ Windows และรองรับสติ๊กเกอร์ความร้อนแบบม้วน **50 × 30 มม.** พร้อมเซนเซอร์จับช่องว่างระหว่างฉลาก
- ตั้งขนาดกระดาษในไดรเวอร์เป็น 50 × 30 มม. และพิมพ์ที่ **100%** จากนั้นพิมพ์และสแกนฉลากทดสอบก่อนใช้งานจริง

## ทดสอบ

```powershell
python -m unittest -q test_qa.py
```

ชุดทดสอบใช้ฐานข้อมูลชั่วคราวแยกจากข้อมูลจริง ครอบคลุมการเพิ่มและแก้ไขสินค้า การรับเข้า/ตัดออก การจัดกลุ่มประวัติรายวัน รูปภาพ Excel การสำรอง/กู้คืน และขนาดหน้าพิมพ์ฉลาก รายละเอียดเพิ่มเติมอยู่ใน [QA-REPORT.md](QA-REPORT.md)

## ขอบเขตการทดสอบ

ทดสอบฟังก์ชันอัตโนมัติและการเปิดไฟล์ `.exe` ที่แพ็กบน Windows แล้ว การพิมพ์และสแกนด้วยอุปกรณ์จริง รวมถึงการติดตั้งบน Windows เครื่องอื่น ยังต้องตรวจรับเมื่อมีอุปกรณ์และเครื่องปลายทาง
