# SP Toys Stock Manager

โปรแกรมจัดการสต๊อกสำหรับ Windows เขียนด้วย Python/PySide6 เก็บข้อมูลใน SQLite บนเครื่อง รองรับสแกนบาร์โค้ดแบบคีย์บอร์ด USB รูปสินค้า รับเข้า ตัดออก ปรับยอด ประวัติ ส่งออก Excel และสำรองข้อมูลรวมรูป

## รันจาก Python

```powershell
python -m pip install -r requirements.txt
python main.py
```

ข้อมูลอยู่ที่ `%LOCALAPPDATA%\SP Toys` และไม่ถูกลบเมื่ออัปเดตโปรแกรม

## สร้างโปรแกรม Windows

```powershell
python -m PyInstaller --noconfirm --distpath output-latest SP-Toys-Stock.spec
```

ไฟล์รันรุ่นล่าสุดอยู่ใน `SP Toys POS\SP Toys POS.exe` คัดลอกทั้งโฟลเดอร์ไปเครื่อง Windows ได้ ไอคอนใน `.exe` ใช้โลโก้ร้านเดียวกับในแอป บน Windows ให้คลิกขวาไฟล์ `.exe` แล้วเลือก **Show more options → Send to → Desktop (create shortcut)** เพื่อสร้างไอคอนบน Desktop มี `installer.iss` สำหรับคอมไพล์ตัวติดตั้งด้วย Inno Setup เมื่อมีโปรแกรม Inno Setup บนเครื่อง

ไฟล์ `.spec` ตัด ICU DLL ที่เครื่องมือแพ็กอาจดึงมาจากแพ็กเกจอื่น เพราะไฟล์เหล่านั้นชนกับ QtCore บน Windows 11 โปรดใช้คำสั่ง `.spec` ข้างบนเมื่อสร้างใหม่

โลโก้อยู่ใน `assets/sp-toys-logo.png` ไอคอน Windows อยู่ใน `assets/sp-toys.ico` และไฟล์ขนาดเล็กคล้าย favicon อยู่ใน `assets/favicon.png` โปรแกรมนี้เป็นแอป Windows จึงไม่มี favicon ของเบราว์เซอร์

## วิธีใช้

เพิ่มข้อมูลสินค้าโดยเว้นช่องบาร์โค้ดได้ โปรแกรมจะสร้างรหัสให้และเริ่มสต๊อกที่ 0 หลังบันทึกเลือกพิมพ์ฉลาก นำไปแปะสินค้า จากนั้นนำเคอร์เซอร์ไว้ในช่องสแกนที่หน้าแรก สแกนเพื่อเลือกสินค้า เลือกจำนวน และกดยืนยันรับเข้า เมื่อต้องการตัดออกให้สแกนเลือกแล้วกดยืนยันตัด เครื่องสแกนที่เลือกซื้อควรตั้งให้ส่ง Enter หลังรหัส บาร์โค้ดจากระบบใช้ Code 128

หน้าประวัติจัดรายการตามวัน โดยวันล่าสุดอยู่บนสุด กดหัวข้อวันที่เพื่อย่อหรือขยายรายการของวันนั้น แต่ละรายการแสดงเวลา สินค้า จำนวนที่เพิ่มหรือลด และเหตุผล

ปุ่มพิมพ์ฉลากจะแสดงตัวอย่างบาร์โค้ดก่อน จากนั้นกด **พิมพ์ฉลาก** ในป็อปอัพเพื่อเลือกเครื่องพิมพ์ หน้ากระดาษตั้งไว้ที่ **50 × 30 มม.** (แนวนอน) หนึ่งรหัสต่อหนึ่งฉลาก ในไดรเวอร์เครื่องพิมพ์ Windows ให้ตั้งขนาดฉลาก 50 × 30 มม. และสั่งพิมพ์แบบขนาดจริง 100% ไม่ใช้ Fit to page จากนั้นพิมพ์ทดสอบและสแกนก่อนพิมพ์จำนวนมาก

ก่อนกู้คืนไฟล์สำรอง ให้สำรองข้อมูลปัจจุบันไว้ต่างหาก Excel ใช้เป็นรายงาน ไม่ใช่ไฟล์กู้คืนเต็มระบบ
